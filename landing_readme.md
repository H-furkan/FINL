# 🧪 Drug Knowledge Assistant

### 🚀 Mini Datathon @ EPAM Systems

---

## 💡 Build Your First RAG System

Welcome to the **Drug Knowledge Assistant Datathon**!

In this challenge, you will design and build a **Retrieval-Augmented Generation (RAG)** system that can answer questions about drugs using real-world-style data.

---

## 🎯 The Mission

You are an **AI Engineer at EPAM** working with a pharmaceutical client.

📉 Problem:

* Drug information exists in documents
* Hard to search
* Hard to extract insights

👉 Your goal:

> Build a system that can **understand questions** and **answer them using data**.

---

## 🧠 What You’ll Build

A complete **AI pipeline**:

```text
User Question → Retrieve Documents → Generate Answer
```

## 💡 Tips for Success

* Start simple (retrieval first)
* Keep your pipeline working end-to-end
* Use only relevant documents for answers
* Don’t overcomplicate models

---

## ⚠️ Important

* ❌ Do NOT send full dataset to LLM
* ✅ Use top 2–3 documents
* ✅ Always have a fallback (no LLM)
